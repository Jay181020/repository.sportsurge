📲 How to Add in Kodi File Manager:

  1. In Kodi, open Settings (Gear) > File Manager > Add source.
  2. Enter the URL: https://jay181020.github.io/repository.sportsurge/
  3. Name the media source: Sportsurge and click OK.
  4. Go back to Settings > Add-ons > Install from zip file > select Sportsurge > click repository.sportsurge-1.0.0.zip.

📺 TiviMate Multi-View (Split-Screen & Quad-Box) Setup:

  1. In TiviMate, go to Settings > Playlists > Add playlist > M3U playlist.
  2. Enter URL: http://127.0.0.1:8899/playlist.m3u (or cloud URL: https://jay181020.github.io/repository.sportsurge/sportsurge.m3u).
  3. Play any channel full screen, then press & hold Select/OK on your remote.
  4. Select the Multi-View grid icon > Add Screen to watch 2, 3, or 4 games at once!
  5. Use D-Pad arrows to switch game audio instantly.
